# Vertretung Mathe

Fertig vorbereitete Mathematik-Vertretungsstunden für die bayerische Realschule (Jahrgangsstufen 5–10), je 35 Minuten. Die Vertretungslehrkraft braucht keine Vorbereitung.

Dieses Repository ist **öffentlich**. Lösungen für die Lehrkraft liegen deshalb nicht hier, sondern in Google Drive.
